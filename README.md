# HolyWorld TNT Auto-Fill 1.9.0 (Fabric 1.21.4)

Второй, отдельный мод. Основная логика работает **без кнопки** сама, но есть клавиша **H**
(меняется в Управление -> HolyWorld), которой можно включить/выключить автозарядку когда угодно -
не нужно каждый раз удалять и заново класть jar в mods, мод просто ставится один раз и потом
включается/выключается H. Пока выключено, мод вообще не смотрит на мир и ничего не делает.
При переключении в чат пишется одна из нескольких случайных фраз ("Орешник включён. Понеслась!",
"Орешник выключён. Отбой." и т.д.).

Когда включено: сам следит за миром. Как только ты вручную
(обычным ПКМ) ставишь **Тнт-Пушку**, мод замечает новый раздатчик рядом с собой и мгновенно:

1. ещё до открытия пушки берёт в руку **редстоун блок** и находит место, куда его ставить;
2. открывает раздатчик и кладёт **Динамит B** (по умолчанию 1 штуку) прямо в центральный слот -
   без проверки результата, максимально быстро;
3. сразу ставит подготовленный **редстоун блок** - пушка стреляет один раз - и пишет в чат
   "FAME: Орешник установлен, клиент скоро 200".

Кирку не трогает - это только автозарядка. Можно ставить вместе с основным мод
(HolyWorld TNT Builder) - id разные, конфликта не будет.

Все сообщения в чат теперь начинаются с "FAME:".

## Как это определяется
Мод помнит, что ты только что держал в руке Тнт-Пушку (в течение `holdWindowTicks` после того,
как убрал её из руки), и следит за раздатчиками в радиусе `scanRadius` блоков вокруг тебя. Как
только появляется новый - и ты недавно держал пушку в руке - мод стартует автозарядку.

**Ограничение:** мод не может отличить твою пушку от обычного раздатчика по виду - только по
тому, что ты только что держал пушку в руке. Если рядом одновременно появится чужой раздатчик
(например, другой игрок), а ты в этот момент держишь пушку - мод может перепутать. Для одиночной
игры/своей стройки это не проблема.

## Использование
- Просто ставь пушку как обычно (ПКМ), ничего нажимать не нужно.
- Нужны Динамит B и редстоун блок в инвентаре заранее.
- Нужны Fabric Loader 0.16.9+, Fabric API, Java 21.

## Живая перезагрузка конфига
Конфиг перечитывается сам раз в секунду, пока игра запущена - **не нужно перезаходить в игру
или переустанавливать мод**, чтобы применить изменения в `holyworld-tntautofill.json` (задержки,
название предметов, текст в чате и т.д.). Просто отредактируй файл и сохрани - через секунду
изменения подхватятся сами. Это не касается изменений в самом коде (Java) - для них всё равно
нужна новая сборка и новый jar.

## Настройки (`.minecraft/config/holyworld-tntautofill.json`)
- `tntPerCannon` - сколько динамита класть (1);
- `holdWindowTicks` - сколько тиков после того, как убрал пушку из руки, ещё засчитывать
  новый раздатчик (20 = 1 сек);
- `scanRadius` - радиус поиска новых раздатчиков вокруг игрока (6 блоков);
- `fillDelayTicks` - пауза перед первым кликом по динамиту (0 - максимально быстро). Если
  динамит перестанет класться - поставь 1-2;
- `clickDelayTicks` - пауза между кликами по слотам; если сервер кикает за скорость - увеличь;
- `chatPrefix` - текст перед сообщениями мода в чате (по умолчанию `FAME:`).

## Сборка
Так же, как первый мод: залей файлы (включая `.github/workflows/build.yml`) в отдельный
GitHub-репозиторий, вкладка Actions -> build -> скачай артефакт, jar без `-sources`.
Локально: JDK 21 + Gradle 8.12, `gradle build`, jar в `build/libs/`.

Имя jar-файла теперь всегда одинаковое (`holyworld-tnt-autofill.jar`, без номера версии) - при
обновлении можно просто перезаписать файл в `mods`, не нужно вручную удалять старую версию.
